# Prism V2.6.1 About Version Correction — 2026-07-14

## Scope and cause

V2.6.1 remains the product version. The prior label hotfix verified the browser title and sidebar, but did not enter Settings **About**. `SettingsPage.tsx` therefore retained a stale `stats?.version || '2.5'` fallback and displayed `2.5` when the system stats response did not include a version.

The correction changes only that fallback to `2.6.1` and expands regression/browser acceptance to all three visible version surfaces. It does not add a version abstraction or change API, schema v17, migrations, search, storage, auth, or exposure boundaries.
