# Prism V2.6 Release Validation — 2026-07-14

## Release Scope

V2.6 publishes the local-first workflow improvements completed after V2.5 and the same-package Go source decomposition completed in GMS-00..10.

User-visible workflow additions:

- Command Palette server-side keyword search.
- Browser-local Saved Search Workspace.
- Full data snapshot export script.
- Batch delete dry-run preview.
- Markdown/TXT import collision preview.
- ReadingView source URL panel.

Maintenance change:

- `go-shadow/main.go` reduced from 10,246 to 1,024 physical lines by moving unchanged declarations into bounded-context files in the same `package main`.

Product boundary:

- Prism remains a personal notebook/knowledge library. V2.6 does not add review metadata or a schema v18 workflow; `status`, `review_state`, and `last_verified_at` remain rejected unless the product purpose changes.
- No AI, semantic search, auth, cloud sync, installer, updater, schema migration, API contract change, or Pi deploy is included.
