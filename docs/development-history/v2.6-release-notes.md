# Prism V2.6

Prism V2.6 keeps the Go-primary, local-first personal knowledge library model and publishes the workflow improvements completed after V2.5.

## Highlights

- Search the full note library from Command Palette using the existing keyword API.
- Save and restore browser-local Search Workspaces without adding server-side preference state.
- Export a complete data snapshot with DB sidecars, uploads, attachments, notes, config, and a SHA256 manifest.
- Preview batch-delete impact before writing.
- Preview Markdown/TXT import collisions before creating notes.
- Show existing source URLs and duplicate URL hints in ReadingView.
- Maintain the Go runtime as bounded-context source files: `main.go` is reduced from 10,246 to 1,024 lines without changing API, schema, migration, data-dir, desktop, or deploy behavior.

Prism remains a personal notebook/knowledge library. This release does not add content-review metadata, AI, semantic search, authentication, cloud sync, installer/updater behavior, or a schema migration.
